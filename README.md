# VAE skip reparameterization

Code, data and numerical results for [*An Input Skip Can Reparameterize a VAE Without Improving the Generator*](https://arxiv.org/abs/2610.37456), Kevin Lee, NeurIPS PriGM 2026.

A constant input skip can reduce reconstruction error while preserving the distribution generated by a Gaussian variational autoencoder. The experiments compare reconstruction and generation on synthetic Gaussian data and NOAA DART records, varying the skip coefficient and observation variance separately.

## Results and reproduction

The [results guide](results/README.md) describes the numerical results for 84 DART fits across seven annual records: energy scores, comparisons with probabilistic principal component analysis (PPCA), and the effects of changing observation variance.

The [training guide](TRAINING.md) describes how to train and evaluate models on one Gaussian dataset and four DART records. The launcher runs 60 training jobs, with four combinations of input skip and observation variance and three training seeds per condition for each dataset. Retraining the three records from 2018 requires preparation inputs and launchers that are outside this release.

The [data guide](data/README.md) lists the NOAA records. HEIGHT is bottom pressure expressed as equivalent water column height in meters.

### Figures

The figure script recreates the paper's ten DART plots from the supplied results and observations.

From the repository root, create a CPU environment:

```bash
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python figures/render.py --output-dir runs/figures
```

The script saves the PDFs in `runs/figures`. It runs on CPU without LaTeX. See the [figure guide](figures/README.md) for units and averaging conventions.

## Tests

```bash
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 python -m pytest \
  -q -rs -p no:cacheprovider tests
```

This command runs the data, metric and plotting tests in the CPU environment. Run the TensorFlow model and integration tests in the separate environment described in the [training guide](TRAINING.md#model-tests).
